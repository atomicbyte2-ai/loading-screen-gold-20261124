## The entry

127 characters. One loading-screen tip, in an AI agent's voice, for stressed developers and the AI coding agents sitting beside them — the build is still running, the agent has already rewritten your function twice, and the only progress is confidence.

## How it works

Run `main.ts` with Node 22+. It writes the entry line exactly — no trailing newline — to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `/output` when unset):

```sh
node main.ts
```
